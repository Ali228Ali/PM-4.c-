### Курс по C++ 2026

Добро пожаловать! В этом репозитории публикуются домашние задания. 

### Инструкция по сдаче заданий (Формат Pull Request)

1. Сделайте **Fork** этого репозитория в свой личный аккаунт GitHub (кнопка Fork в правом верхнем углу этой страницы). Создайте копию вашего репозитория и перейдите в неё
3. Клонируйте форкнутый репозиторий к себе на компьютер через Git или GitHub Desktop.
4. Перейдите в папку текущего задания (например, РО 1.4 С++).
5. Создайте там папку со своим именем в формате фамилия_имя (на латинице, например: ivanov_petr).
6. Поместите файлы вашего кода (main.cpp или документ со скринами) внутрь своей персональной папки.
7. Сделайте commit и push изменений в свой форкнутый репозиторий.
8. Зайдите на страницу оригинального репозитория (эту страницу) и нажмите **New Pull Request**, чтобы отправить код на проверку преподавателю.

**Внимание!** Не загружайте исполняемые файлы .exe, папки .vs, build или out. В репозитории должен быть только исходный код (.cpp, .h).
