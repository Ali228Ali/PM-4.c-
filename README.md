### Курс по C++ 2026

Добро пожаловать! В этом репозитории публикуются домашние задания. 

Инструкция по сдаче заданий (Формат Pull Request)
1.Сделайте Fork этого репозитория в свой личный аккаунт GitHub (кнопка Fork в правом верхнем углу этой страницы).
2.Клонируйте форкнутый репозиторий к себе на компьютер через Git или GitHub Desktop.
3.Перейдите в папку текущего задания (например, РО 1.4 С++)
4.Создайте там папку со своим именем в формате фамилия_имя (на латинице, например: ivanov_petr).
5.Поместите файлы вашего решения внутрь своей персональной папки. Это может быть код (main.cpp) и/или документ со скриншотами (в формате PDF, DOCX или отчет в Markdown).
6.Сделайте commit и push изменений в свой форкнутый репозиторий.
7.Зайдите на страницу оригинального репозитория (эту страницу) и нажмите New Pull Request, чтобы отправить код и документы на проверку преподавателю.
